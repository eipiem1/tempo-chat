## Resources

- [Tempo Documentation](https://docs.tempo.xyz)
- [Privy Documentation](https://docs.privy.io)
- [Viem Documentation](https://viem.sh)

You are going to implement natual language interface for Tempo operations according to Resources listed above.

For examples:
- "What's my portfolio worth?"
- "Swap $100 of AlphaUSD for BetaUSD"
- "Set up a weekly transfer to savings"

Firstly you need to figure out all basic Tempo operations to be implemented by reading Resources, then make a plan to implement one by one. Please note there are llms.txt and llms-full.txt on (tempo website)[https://docs.tempo.xyz/guide/building-with-ai]. And you may use Privy to auth with email/phone, and use Viem to implement.
